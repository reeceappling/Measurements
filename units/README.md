# Units
Module for units of measure, and their conversion rates.
Units can be
- singular base (like meters)
- singular compound (units made of other units, but under one symbol) (like Newtons) <span style="color:red;">CONFIRM NAME CORRECT</span>
- compound (like ft/s^2) <span style="color:red;">CONFIRM NAME CORRECT</span>
- unitless (units of count) (like a dozen)

Units are always static <span style="color:red;">CONFIRM</span>

Conversion rates can be static or dynamic.
